# WinWork 客户端 UI 设计文档

**日期**: 2026-05-19
**版本**: v0.2.20
**状态**: 已批准

## 概述

WinWork 是一个 Windows 桌面客户端应用，基于 Tauri 框架构建，提供文件管理、AI 智能对话和知识库功能。

## Header 组件

### 布局
```
┌──────────────────────────────────────────────────────────────────┐
│ [Logo] winwork    |    Status    | Ver | [日志/详情] [─][□][×] │
└──────────────────────────────────────────────────────────────────┘
```

### 元素
| 元素 | 描述 |
|------|------|
| Logo | 48x48 深色圆角方形，内部文件夹图标 |
| 标题 | "winwork"，font-bold, 15px |
| API状态徽章 | 绿色圆点 + "API 已连接" / 黄色圆点 + "未就绪" |
| 版本号 | "v0.2.20"，圆角药丸样式 |
| 日志/详情按钮 | 图标 + 文字，点击打开右侧面板，记住上次Tab状态（详情/诊断） |
| 窗口控制 | 最小化(─) / 最大化(□) / 关闭(×)，关闭按钮悬停变红 |

### 窗口控制
- `decorations: false` 自定义标题栏
- 最小化: 调用 `window.minimize()`
- 最大化: 调用 `window.maximize()` / `window.unmaximize()`
- 关闭: 调用 `window.close()`
- 拖拽区域: 除窗口控制按钮外的整个 Header

## 右侧面板组件

### 模式切换
```
┌─────────────────────────────────────┐
│ [📋 详情] [🔍 诊断]           [✕]   │
├─────────────────────────────────────┤
│ 详情:                               │
│ [文件内容] [执行链路] [数据溯源]      │
│                                     │
│ 诊断:                               │
│ [启动日志] [调用日志] [错误定位]      │
└─────────────────────────────────────┘
```

### 面板状态
| 状态 | 行为 |
|------|------|
| 收起 | `transform: translateX(100%)` |
| 展开 | `transform: translateX(0)`, 阴影效果 |
| Tab状态持久化 | 记住用户上次选择的Tab（详情/诊断），下次打开时恢复 |
| 状态 | 行为 |
|------|------|
| 收起 | `transform: translateX(100%)` |
| 展开 | `transform: translateX(0)`, 阴影效果 |

### 详情Tab: 执行链路
5步骤可视化流程：
1. 用户输入 (蓝色圆点)
2. AI解析意图 (绿色圆点)
3. wind-cli执行 (琥珀色圆点)
4. 返回结果 (紫色圆点)
5. AI格式化回复 (绿色圆点)

每步骤之间用竖线连接。

### 详情Tab: 数据溯源
- 输入数据卡片
- 工具调用卡片 (含命令、上下文)
- 输出数据卡片
- 安全校验通过卡片 (绿色背景)

## 技术实现

### 框架
- Tauri v2
- 前端: HTML + CSS (Tailwind类) + Vanilla JS
- 无构建依赖，CDN依赖已移除

### 状态管理
- localStorage: API Key (XOR混淆)
- Tauri invoke: workspace state persistence

### 通信
- `invoke()`: 前端→Rust后端命令调用
- `window.__TAURI__`: Tauri API访问

### 日志系统
- 前端: `window._log()` 缓冲区 (最多200条)
- 诊断面板实时显示
