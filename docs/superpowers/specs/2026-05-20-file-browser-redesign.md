# 文件浏览器 UI 重新设计

日期: 2026-05-20

## 背景
wind-cli 的 workspace 包含文件和多层级子文件夹，其中 `wiki/` 是知识库目录。
原设计把"工作区"和"知识库"作为两个独立区块，不符合实际文件层级。

## 设计目标
1. 统一的树形文件列表，支持展开/折叠子文件夹
2. 文件详情在右侧滑出面板显示
3. 简约现代的图标系统

## 布局变化

### 移除
- 左侧分离的"工作区"和"知识库"区块
- 多余的按钮（刷新、打开文件夹独立按钮）

### 新增
- 单一树形文件列表
- 右侧文件详情滑出面板
- 顶部工具栏：🔄 刷新、📂 打开

## 交互

| 操作 | 结果 |
|------|------|
| 点击文件夹 | 原地展开/折叠子内容 |
| 点击文件 | 右侧滑出文件详情面板 |

## 文件详情面板
- 从屏幕右侧滑入
- 显示：文件图标、文件名、文件大小、内容
- 顶部有关闭按钮
- 可拖拽调整宽度

## 图标系统
使用 Lucide 风格 SVG 图标：
- `chevron-right` / `chevron-down` - 展开状态
- `folder` / `folder-open` - 文件夹
- `file` / `file-text` - 文件
- `refresh-cw` - 刷新
- `external-link` - 打开文件管理器
- `x` - 关闭面板

## 样式
- 展开的文件夹显示 `▼`，折叠显示 `▶`
- 支持多层级嵌套展开
- hover 效果区分可点击区域
- 文件详情面板带阴影和圆角

## 实现文件
- `src/index.html` - 布局结构调整
- `src/styles.css` - 样式更新
- `src/js/app.js` - 树形渲染逻辑
- `src/js/ui/file-panel.js` - 新建文件详情面板组件
